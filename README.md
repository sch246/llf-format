# LTF — Line-Typed Format

一种零转义、格式上不可注入、可流式的数据格式。**格式本身不写类型**：标量的类型由使用者的 schema 声明，结构由 `{}` / `[]` 标出，null 写 `_`。主要面向大模型的工具调用，也适合手写。

```
# 工具调用：类型由 schema 声明，消息里不写
call - write_file
id - c1
args {}
  path - src/main.py
  mode - 644
  overwrite - true
  backup _
  content -
    |def f():
    |    return "call - fake"   # 不需要任何转义
    |

```

## 特点

- **零转义**：多行文本每行以 `|` 开头，之后的内容原样保留。
- **不可注入**：内容永远在 `|` 之后；由符合规范的编码器写出的内容不可能变成结构行。
- **无类型**：`-` 只表示“一个非 null 标量”，string / int / float / bool 由 schema 决定；`_` 是 null；`{}` / `[]` 是结构。
- **可流式**：每行的含义只由环境、缩进和首字符决定，可以边生成边解析。
- **可检测截断**：消息以空行结束，中途断开会被识别。

## 相关项目

[NestedText](https://nestedtext.org) 同样用行前缀免除转义，也把标量类型交给应用层。LTF 的结构更显式（`{}` / `[]` 必须写出，空容器无歧义），并增加了流式语义与截断检测，定位于机器生成。
