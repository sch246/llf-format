# LTF — Line-Typed Format

一种零转义、格式上不可注入、可流式的数据格式，主要面向大模型的工具调用，也适合手写。

```
call ~ write_file
args {}
  path ~ src/main.py
  mode % 644
  content ~
    |def f():
    |    return "call ~ fake"   # 不需要任何转义
    |

```

## 特点

- **零转义**：多行文本每行以 `|` 开头，之后的内容原样保留。
- **不可注入**：内容永远在 `|` 之后，任何内容都无法伪装成结构。
- **显式类型**：`~` 字符串、`%` 整数、`/` 浮点、`?` 布尔、`_` null、`{}` 键值对、`[]` 列表、`@name` 扩展。
- **可流式**：每行的含义只由自身决定，可以边生成边解析。
- **可检测截断**：消息以空行结束，中途断开会被识别。
